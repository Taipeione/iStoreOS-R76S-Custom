## Repair

The next cloud build pins Cargo transport behavior in the workflow:

- `CARGO_HTTP_MULTIPLEXING=false` to avoid the observed HTTP/2 framing path;
- `CARGO_NET_RETRY=10` for transient registry fetch failures;
- `CARGO_HTTP_TIMEOUT=120` for bounded but practical crate downloads.

These settings preserve the locked `Cargo.lock`, the `shadowsocks-rust` package,
and the ARM64/RK3576 target. They do not mask compiler or package errors.
