`https://github.com/Openwrt-Passwall/openwrt-passwall-packages/releases/download/dns2socks/SourceCode.zip`

the package source name is not present there. The package then stopped at:

`No more mirrors to try - giving up.`

`make[3]: *** .../dl/SourceCode.zip Error 2`

`ERROR: package/feeds/passwall_packages/dns2socks failed to build.`

The final `make world` exit code was a consequence of this package download failure.

device-DTS, RK3576 target, kernel ABI, rule audit, AppleEcosystem, WeChatDirect,
PassWall/PassWall2 configuration, or APK packaging failure.
