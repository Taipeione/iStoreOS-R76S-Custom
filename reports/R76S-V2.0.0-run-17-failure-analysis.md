## First real failure

The first terminating audit error was an assertion in the `Rule Audit` job:

```text
AssertionError: Disney
```

The inline Rule Audit list used legacy names (`Disney`, `Netflix`, `Nintendo`,
`Telegram`, `TikTok`) while the importer and the Firmware Audit gate use the
canonical independent-group names `DisneyApp`, `NetflixApp`, `NintendoApp`,
`TelegramApp`, and `TikTokApp`. The generated manifest therefore correctly
contained 11 groups, but the Rule Audit rejected the valid `DisneyApp` group.

Firmware Audit failed for the same class of inconsistency: its gate expected
the canonical `*App` names, while the separate Rule Audit expected the shorter
legacy names. This is a CI audit assertion defect, not a firmware, package,
kernel, target-device, SmartDNS, DNS2SOCKS, or domain-input failure.
