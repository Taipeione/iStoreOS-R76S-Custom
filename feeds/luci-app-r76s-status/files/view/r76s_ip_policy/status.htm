启用前检查

请先手动启用 SmartDNS，并配置 cn 与 foreign 上游组。全局 AAAA 过滤须关闭。若有用户自定义域名规则，应先确认其优先级。

策略默认不启用。启用只增加独立配置文件，不修改 DNS 转发链，也不会启动或重启服务。

SSH 检查与操作：

/usr/libexec/r76s/r76s-ip-family-policy check
/usr/libexec/r76s/r76s-ip-family-policy enable
/usr/libexec/r76s/r76s-ip-family-policy disable

需要防止缓存或硬编码 IPv6 地址绕过时，先关闭流量卸载、确认国内 IPv6 路由列表，再使用独立保护工具：

/usr/libexec/r76s/r76s-ip6-guard check
/usr/libexec/r76s/r76s-ip6-guard enable
/usr/libexec/r76s/r76s-ip6-guard disable

保护工具启用时会保存备份并重新加载 firewall、SmartDNS；仅管理独立规则表。微信/腾讯保持双栈，查询得到的 IPv6 地址写入允许集合。

保存后在 SmartDNS 管理页手动重新加载服务，并测试国内 A/AAAA、国外 A/AAAA 查询。

DNS 策略本身不能阻止硬编码 IPv6。启用出站保护后，仅允许国内 IPv6 网段、已解析的国内/微信/腾讯 IPv6 地址、LAN 和必要本地/控制流量。IP 白名单无法区分共享同一 CDN 地址的域名；外部加密 DNS 的回答不由本页面控制。
