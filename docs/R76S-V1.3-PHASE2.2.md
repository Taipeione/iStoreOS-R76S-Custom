# R76S-V1.3 Phase2.2：WireGuard 用户体验增强

开发分支：`feature/R76S-V1.3`。本阶段无完整编译、无 Release，未提交或推送。

## 页面入口与行为

- 网络 → WireGuard 管理：接口概览及逐 Peer 表格。显示配置名称、接口启停、近期握手、最后握手时间、累计接收/发送及接口采样速率。
- 网络 → WireGuard 客户端生成：填写服务器公钥、公网 Endpoint、客户端隧道地址及路由，生成标准配置；可使用已有私钥或通过原生 WireGuard RPC 生成新密钥。
- `.conf` 下载供 Windows/iPhone 等客户端导入；点击显示二维码后可在手机 WireGuard App 扫码导入。二维码使用固件已有 LuCI uqr 库本地渲染。
- 服务器 Peer 必须手动添加；页面给出客户端公钥及服务器 Peer 的 `/32`、`/128` AllowedIPs 提示。不会自动修改 network、Firewall、DNS 或 PassWall。
- 原生接口编辑、配置导入和 WireGuard 状态页面保留。

最近 180 秒握手标为“近期握手”；旧握手标为“空闲 / 待确认”，不能据此判定断线。还区分尚无握手、接口停止、配置禁用、时间异常及检测失败。

状态每 5 秒刷新，后台页面暂停。请求失败保留上次状态并提示。速率按相邻快照计算；接口停止或流量计数降低时不显示错误的负速率。

默认客户端 AllowedIPs 为 `0.0.0.0/0, ::/0`；双栈全隧道需要服务器提供 IPv6 地址、路由及转发。仅指定 IPv4 默认路由不会约束客户端本地 IPv6 出口。页面不自动更改 Phase2.1 IPv6 防绕过策略。

## 密钥与输入处理

配置和二维码含客户端私钥；生成结果只留在当前页面。输入改变、主动清除或 pagehide 时清空结果；不使用浏览器持久存储。下载文件由用户保管。

密钥生成/推导使用既有 `luci.wireguard` RPC 和原生 ACL，不增加密钥 HTTP 接口。生成页不读取服务器私钥。状态 JSON 不返回任何密钥或原始 UCI 配置。

校验 Base64 密钥、CIDR、DNS IP、Endpoint、端口、Keepalive、MTU 和可移植文件名；拒绝换行注入。二维码内容过长时提示使用配置文件导入。
