## DNS 链路诊断

入口：状态 → DNS 链路诊断。

检查系统 resolv.conf 入口、dnsmasq/SmartDNS/AdGuard Home 进程与端口归属、可识别的本机上游转发、潜在回环、默认上游缺失、WAN 下发 DNS 及 PassWall/PassWall2 同时启用。

优先读取 procd 指定的 dnsmasq 运行配置；不具备运行路径信息时才退回默认目录或 UCI，标为覆盖不完整。读取 resolv 文件和 AGH 的服务声明配置路径。SmartDNS 识别 musl loader 启动参数。可选服务未启用显示信息；dnsmasq port=0 表示禁用 DNS，不误报 DHCP 服务故障。

只做本机只读检查，不发送外部 DNS 查询。外部上游地址和 URI 认证信息不输出。SmartDNS 自定义组、include、代理生成配置、条件转发及不同绑定地址不能全部解析；回环结果为可能配置回环，不是实际解析成败证明。页面始终呈现覆盖范围限制。

## 主路由安全状态

入口：状态 → 主路由安全检查。

- root 无密码、锁定、已知默认密码、已设置密码或无法确认状态。使用本地 crypt 检查固定基线默认密码；页面不输出密码或哈希。
- fw4 表是否存在、WAN/wan6 区域 input/forward 配置及继承默认策略。
- WAN/全局 UCI 入站规则允许管理端口的情况，包括自定义 SSH/HTTP/HTTPS 端口与端口范围；ICMP 允许规则不会误判管理端口开放。
- WAN 本机 DNS 端口 53 允许规则。
- 管理服务通配监听配置、UPnP、端口转发数量及 WAN 链路。
- 代理配置启用时的独立 IPv6 guard 规则状态，以及 guard 与流量卸载同时配置的情况。

检查不改密码、DNS、服务、防火墙或 IPv6 策略。配置检查通过不等于 WAN 不可达；自定义 nft include、UPnP 动态规则、上游 NAT 和真实远端可达性需设备验证。未知数据不会显示为安全通过。
