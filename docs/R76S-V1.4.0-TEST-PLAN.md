# 验收计划

自动检查：全部现有回归、新服务状态组合/互斥/失败恢复、规则集合和顺序、最终控制器适配、Lua/JS/shell 语法、实际 SquashFS、镜像/manifest/签名一致性。真实固件 UCI 测试涵盖七项服务状态的 128 种组合。测试报告必须保留跳过原因。

实机待验收：

1. TF/eMMC 启动，DHCP/PPPoE、WAN6/PD、认证与默认关闭策略。
2. V1.2.3→V1.4、V1.4→下一候选；在线/LuCI/CLI，保留和清空配置。
3. 下载中断、错误签名/摘要/设备、空间不足、提交失败、并发请求、同版本/降级拒绝。
4. 两套代理单独启用、节点/订阅保存、TCP/UDP、启停与重启；默认状态和高级 ACL 分开验收。
5. 代理三态×SmartDNS两态×AGH两态，检查回环、监听、查询与 DNS 故障回退。
6. 国内 A/AAAA、国外 A/AAAA 抑制、硬编码 IPv6/外部 DNS、旧连接、缓存、fw4 reload、掉电重启。
7. 微信聊天、语音/视频、图片原图、文件、小程序、朋友圈、CDN 切换，记录实际出口。
8. WireGuard 双角色、二维码导入、远端握手、A/AAAA/DDNS 变化、IPv6 guard 共存及路由递归检查。
9. 至少七天长稳；反复 WAN 重连和服务重启，不出现内存增长、规则累积、节点丢失。

每项记录源码提交、镜像 SHA256、设备、配置、步骤、期望/实际及脱敏日志。编译成功不能将上述项目自动标记为通过。
