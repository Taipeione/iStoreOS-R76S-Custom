# R76S-V1.2.3 OTA 维护版

以 V1.2.2 的 `1daed16ac79d66666847bca6e4c29bc5f4c88b95` 为固定基线。
仅修复 OTA 前置状态保存：首次运行自动建立 `/etc/config/r76s_ota_state`，
写入 `config state 'state'`，再执行原有 UCI 保存和提交。
保存 PassWall、PassWall2、SmartDNS、AdGuardHome 的 init 状态和前三者的 UCI enabled。
分流规则、DNS、WireGuard、IPv6、防火墙均沿用 V1.2.2。

## V1.2.2 设备先修复前置脚本

新镜像中的脚本只有刷入后才生效，无法修复刷入前运行的旧脚本。
从此 Release 下载 `r76s-ota-preserve-state` 和 `ota-helper.sha256`，
先在下载目录执行 `sha256sum -c ota-helper.sha256` 校验。
通过 SCP 将脚本复制到路由器 `/tmp/r76s-ota-preserve-state`。
然后在路由器 SSH 中执行：

```sh
set -e
sh -n /tmp/r76s-ota-preserve-state
cp -p /usr/libexec/r76s/r76s-ota-preserve-state /root/r76s-ota-preserve-state.v122.bak
cp /tmp/r76s-ota-preserve-state /usr/libexec/r76s/r76s-ota-preserve-state
chmod 755 /usr/libexec/r76s/r76s-ota-preserve-state
```

随后重试保留配置的在线升级；也可下载 V1.2.3 镜像后通过 LuCI 保留配置升级。
Release 不替换 V1.3.2 的 Latest 标记，因此在线检查可能继续提供 V1.3.x。
不提前手动运行保存脚本，以免提前留下 pending 状态。
