# R76S-V1.4.4

R76S-V1.4.4 is the formal iStoreOS 24.10.8 maintenance release for FriendlyElec NanoPi R76S (RK3576/ARM64).

This release hardens PassWall and PassWall2 startup: the persistent UCI intent is synchronized with the real `/etc/rc.d` autostart links, native start/restart operations are guarded by the R76S service manager, and the two transparent proxy engines are mutually exclusive. Existing Xray, ChinaDNS-NG, DNS, nftables, IPv4/IPv6, wan_6, 43-rule routing, OTA, and deterministic root authentication behavior from V1.4.3 are retained.

Clean images keep LAN at 192.168.50.1/24 with a DHCP WAN client, and PassWall, PassWall2, SmartDNS, and AdGuard Home remain disabled until the administrator enables them. Preserve-config upgrades retain user network, node, subscription, rule, and service state.

The OTA metadata and checksums are generated from the exact published image. Hardware validation remains the responsibility of the device operator; the build workflow never flashes a device.
