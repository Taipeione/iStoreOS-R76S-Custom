# R76S-V1.4.3

R76S-V1.4.3 is the formal iStoreOS 24.10.8 release for FriendlyElec NanoPi R76S (RK3576/ARM64).

The release carries the V1.4.2 networking, DNS, PassWall, IPv6, LuCI, plugin-center, health-check, and OTA transaction fixes. The root authentication policy is deterministic: clean images contain the fixed initial credential policy, and a preserved configuration is migrated once on the first V1.4.3 boot. After that migration, an administrator may change the root password normally; later boots do not overwrite that change.

The image defaults LAN to 192.168.50.1/24 and WAN to DHCP on a clean installation. Existing configuration is retained by sysupgrade unless the operator explicitly chooses otherwise.

The OTA metadata and checksums in this release are generated from the exact published image. Hardware validation remains the responsibility of the device operator; no device is flashed by the build workflow.
