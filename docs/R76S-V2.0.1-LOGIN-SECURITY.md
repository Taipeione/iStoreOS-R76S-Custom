# R76S-V2.0.1 登录安全

- 用户名：`root`
- 干净镜像初始密码：`password`
- 密码存储：SHA-512-crypt `/etc/shadow` 哈希，不在公开源码、BuildInfo 或构建日志写入明文。
- 保留配置升级：保留现有 `/etc/shadow`，不会覆盖管理员已修改的密码。
- SSH：启用 root 密码登录，但 Dropbear 绑定 LAN 接口，不作为 WAN 管理入口。
- LuCI：使用同一个 root 认证数据库。

首次登录后必须立即执行密码修改，例如：

```sh
passwd
```

`password` 只是首次安装的临时初始凭据，不应长期使用，也不应暴露到公网或 WAN。
