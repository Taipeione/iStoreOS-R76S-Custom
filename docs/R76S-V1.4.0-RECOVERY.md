# 恢复流程

刷写前准备已验证的 TF 卡、V1.2.3 镜像、配置备份和 UART。固件没有已验证的 A/B 自动回滚，不保证断电后能够自行恢复。

升级前检查失败时不要刷写；查看 `/tmp/r76s-ota/state.json`、下载日志和 preserve 日志。刷写期间不要断电。新系统启动后恢复失败，查看 `/tmp/r76s-ota-restore.log` 与 `r76s_ota_state`，先修复配置/依赖，再重试恢复。

DNS 模式操作失败会恢复事务前配置；`/etc/r76s/dns/transaction` 保存恢复依据。`system` 模式只恢复原有 dnsmasq 上游字段。不要在未经核对时删除事务锁或覆盖备份。

需要恢复 V1.2.3 时，优先从独立 TF 启动已知镜像。备份新系统配置后，按旧版本支持范围手动恢复；先移除不兼容的 IPv6 guard include，再恢复网络。不要将新版本全部配置盲目保留到旧固件。

干净镜像首次启动使用默认 root 密码 `password`；保留配置升级保留现有 root 密码。
