# V1.2.3 → V1.4.0

1. 导出 sysupgrade 配置备份，额外保存自定义路径的 AGH YAML、节点文件、WireGuard 密钥和 DDNS 凭据。
2. 记录 UCI/init/运行状态和两套代理节点、订阅、规则摘要。解决双透明代理同时启用。
3. 下载镜像及校验清单，检查 SHA256、设备、当前启动介质和可用空间。
4. 使用标准 LuCI 保留配置升级，或已有可工作的在线升级入口。V1.2.2 先修复旧 helper。
5. 新系统恢复旧快照，合并缺失的固件管理规则，用户节点及已有规则值优先。新服务协调器使持久 UCI 意图与 init 状态一致。
6. 检查 DNS、代理、WireGuard、认证和 WAN；恢复失败保留标记，不把 restart 返回成功当成完整健康。

默认不接管已有 DNS。迁移涉及的旧版本生成器、keep list 和恢复钩子暂保留兼容职责；已删除的仅为重复页面、历史规则 shell 数据及废弃自动启用入口。
