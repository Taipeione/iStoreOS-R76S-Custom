# R76S-V2.0.0 test plan

## Evidence levels

Results are reported separately as static checks, build checks, offline/simulated checks, and physical TF-device checks. A build result never implies a boot or production-router result.

## Static and build checks

- Verify OpenWrt source commit, `rockchip/armv8`, `friendlyarm_nanopi-r76s`, DTS/profile, RK3576 image recipe, U-Boot/SPL inputs, kernel release and kmod ABI.
- Verify the AMD64 Colima/QEMU build stages separately: host tools, cross toolchain, target kernel, target packages, rootfs, and final firmware.
- Run the application importer with all 11 inputs, without `--allow-missing`; require zero malformed lines and zero duplicate findings.
- Verify the 43 baseline rules, the additive application block, exact source-domain retention, `WeChatDirect` TCP/UDP direct mapping, and absence of broad `domain:qq.com` in that rule.
- Verify `AppleEcosystem` has no forced outbound option and is written to both PassWall and PassWall2 default configurations.

## Runtime checks on an isolated TF test device

Check system/kernel/DTB identity, both RTL8125BG interfaces, LAN `192.168.50.1/24`, PPPoE WAN, IPv4/IPv6, USB/PCIe/storage, `dnsmasq:53 → ChinaDNS-NG:15355`, direct AdGuard Home `:3053`, SmartDNS `:6053`, and Xray DNS `:15353 → 1.1.1.1`.

Test these domains: `www.baidu.com`, `www.google.com`, `chat.openai.com`, `chatgpt.com`, `github.com`, `www.youtube.com`, `www.netflix.com`, `weixin.qq.com`, and `file2.wx.qq.com`.

Inspect both PassWall and PassWall2 UCI runtime rule sections after migration and reboot. Confirm `AppleEcosystem` exists, its domain count matches the audit, its TCP/UDP network value is present, and its outbound strategy is inherited rather than forced. Confirm WeChat TCP and UDP remain direct and that no broad `qq.com` rule appears.

## OTA and persistence checks

Use only a signed test package on a disposable TF test installation. Verify package integrity, selective migration, LAN/PPPoE/DNS/PassWall/PassWall2/SmartDNS/AdGuard settings, Apple rules, user-defined rules, reboot persistence, and failure rollback. Do not restore the old iStoreOS configuration wholesale. Do not flash the production eMMC and do not publish Stable OTA from these tests.
