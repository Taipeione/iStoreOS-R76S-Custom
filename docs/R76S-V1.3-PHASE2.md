# R76S-V1.3 Phase2 设计与实现

分支：feature/R76S-V1.3。此阶段只实现和测试，不编译、不发布。

## 1. 国内 IPv4 + IPv6

新增独立的 r76s-ip-family-policy 工具，由升级组件包安装。SmartDNS 根据
/usr/share/passwall/rules/chnlist 分类；国内域名使用 cn 上游组，允许 A/AAAA，
关闭域名级双栈优选，避免只保留一个地址族。lan、home.arpa、localhost 保留
IPv6 和原解析器选择。需要 WAN IPv6、地址分配和实际上游 AAAA 支持。

## 2. 国外 IPv4 only

非国内列表域名使用 foreign 组，通过 -address #6 抑制 AAAA；A 正常解析。
这是 DNS 域名策略，不是 IP 地理定位或 IPv6 防火墙。硬编码 IPv6、自带 DoH、
用户更具体域名规则可能绕过该策略；本阶段不改变 IPv6 路由、转发及防火墙。

工具支持 render、check、enable、disable。默认没有启用配置。enable 检查：
SmartDNS 已启用、国内列表非空、两个上游组有效、无待保存配置、无全局 A/AAAA
过滤。工具只追加自己的 conf_files 项；不删除或重建上游、不更改 dnsmasq、
PassWall、PassWall2 或 AGH，也不重启服务。保存后由用户手动重启 SmartDNS。
删除仅移除本工具的 include。每次变更保存备份，失败恢复原配置；并发操作
使用目录锁。异常断电留下锁时需先检查备份和 UCI 再人工处理，不自动恢复。

配置文件：/etc/smartdns/r76s-v13/ip-family.conf，加入 OTA keep.d 保存列表。
上游组可用 R76S_POLICY_CN_GROUP、R76S_POLICY_FOREIGN_GROUP 指定，列表可用
R76S_POLICY_CN_FILE 指定。R76S_POLICY_ROOT 只用于隔离测试。高级自定义
SmartDNS 配置需要另行审查；工具的预检不能证明整个 DNS 链路可用。

“服务 → 国内 / 国外 DNS 策略”提供只读预检、配置状态和启用说明，无执行按钮。

## 3. WireGuard LuCI 增强

新增“网络 → WireGuard 管理”：配置/运行 Peer 数、接口状态、最近 180 秒握手、
最后握手及累计流量，并链接原生接口和状态页。状态采集不读取私钥或 PSK。
空闲 Peer 的旧握手不作为掉线证据；未来时间戳提示时钟待校准。
iPhone 二维码、Windows 标准 .conf 仍沿用原生 LuCI；不生成预置密钥、接口、
默认路由或防火墙规则。

## 4. AdGuard Home 状态

同时检查 procd、精确进程 PID、配置和端口归属，区分关闭、启用未运行、配置
未知、端口未确认和 DNS 端口已监听。默认 YAML 或 procd 声明的配置路径优先。
配置元数据只支持常见块式 YAML；不使用它验证完整 YAML 语法。
只有可确认归属于 AGH 的非回环 Web 端口才显示管理入口。当前入口使用 HTTP；
HTTPS-only 或反向代理需要自行访问既有地址。端口监听不等于实际 DNS 成功。
默认关闭和不接管 DNS 的策略保持不变。

## 5. OTA UI

增加三步流程卡片、窄屏布局、状态播报及减少动画模式。原 JavaScript、DOM ID、
API、SHA256/metadata/sysupgrade 检查和恢复脚本保持不变；仅新增 DNS 策略
配置的保留路径。版本仍为 R76S-V1.3。

  iPhone/Windows 连接、AGH 运行状态及保留配置 OTA。当前测试不能替代实机验收。
