# R76S-V1.3.2 OTA preserve-state 修复

首次运行先以 0600 权限创建 /etc/config/r76s_ota_state，缺失或空文件初始化命名 state section，已有 state section 直接复用；已有其他 section 保留。同步修改构建生成器，避免 stage 16 覆盖修复。

PassWall、PassWall2、SmartDNS 的 UCI 开关，以及四个服务（含 AdGuardHome）的 init 开关继续保存。双代理冲突、提交失败、落盘校验失败继续阻止 OTA。

真实设备测试兼容（需 Python 3，在仓库目录执行）：

```sh
R76S_TEST_UCI=/sbin/uci R76S_TEST_SHELL="busybox ash" python3 build/local-arm64/tests/test_v131_ota_state.py -v
```

测试使用临时 UCI 配置和模拟 init 脚本，不修改设备 /etc/config、不启停真实服务、不刷机。也支持 R76S_TEST_ROOTFS 指定已解包固件，在 ARM64 Linux 上执行真实固件 UCI。

已安装 V1.3.1 的设备在 OTA 前运行旧 helper，因此目标镜像中的修复无法修复本次升级前的旧 helper。可先安装本仓库修复后的 files/usr/libexec/r76s/r76s-ota-preserve-state 至设备同名路径（权限 0755），然后重试 OTA。未获得设备连接信息，本次未执行实体设备升级。
