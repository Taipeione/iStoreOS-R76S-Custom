# R76S-V1.4.6

R76S-V1.4.6 is the iStoreOS 24.10.8 maintenance release for FriendlyElec NanoPi R76S (RK3576/ARM64), based on the verified R76S-V1.4.5 configuration-preserving baseline.

This release adds a registry-driven plugin lifecycle contract. LuCI configuration changes are delivered through explicit UCI configuration events, so a user-enabled PassWall, PassWall2, or SmartDNS service is synchronized with its init state and started without an SSH repair step. Services that are disabled remain disabled; init-link-owned services such as Docker, DDNS, ttyd, and PassWall server components are not force-enabled.

OTA state snapshots preserve registered UCI intent and actual rc.d autostart state across a V1.4.5 → V1.4.6 preserve-config upgrade, with legacy V1.4.5 fields accepted during migration. Restore is fail-closed and retains its pending marker when a required service or configuration cannot be restored.

PassWall and PassWall2 remain mutually exclusive transparent-proxy clients while their server services and user configuration remain independent. The existing LAN, WAN DHCP, PPPoE, IPv4/IPv6, wan_6, DNS, firewall, routing rules, and root authentication policies are retained.

Automated source, package, shell, OTA, and simulated lifecycle tests do not constitute physical R76S validation. Hardware clean-flash, first-enable, reboot/power-loss, and OTA acceptance remain required before production promotion.
