# R76S-V2.0.1 OTA 升级指南

## 适用范围

本指南适用于已运行 R76S-V2.0.0、目标为 FriendlyElec NanoPi R76S / RK3576 的设备。
正式固件必须从 GitHub Release 下载，并使用 Release 中的 `SHA256SUMS` 校验。

V1.4.6 不支持直接执行本指南的普通 sysupgrade；请先阅读
`R76S-V2.0.1-OTA-COMPATIBILITY.md`。

## LuCI 网页升级

### GitHub 在线升级

1. 登录 LuCI，打开“系统 → R76S 在线升级”。
2. 点击“检查更新”，确认版本、设备型号和目标为 `friendlyarm,nanopi-r76s`。
3. 点击“下载固件”，等待 SHA256、Metadata、OTA 签名和 `sysupgrade -T` 全部通过。
4. 确认启动盘检查显示当前运行介质，并点击“在线升级并保留配置”。
5. 升级期间不要断电；设备重启后用 LAN 地址重新登录。

### 手工上传

也可以使用 OpenWrt 标准 LuCI“系统 → 备份/升级 → 刷写新固件”上传
`openwrt-rockchip-armv8-friendlyarm_nanopi-r76s-squashfs-sysupgrade.img.gz`。

上传前必须从同一 GitHub Release 获取 `SHA256SUMS`，在本地校验镜像；LuCI 的设备兼容性检查和
“保留配置”选项不得被强制跳过。V1.4.6→V2.0.1 不得用此方式直接上传。

## SSH 在线升级

仅对 V2.0.0→V2.0.1 同布局升级使用：

```sh
/usr/libexec/r76s/r76s-ota check
/usr/libexec/r76s/r76s-ota download
/usr/libexec/r76s/r76s-ota verify
/usr/libexec/r76s/r76s-ota install
```

后端会检查版本、设备 Metadata、SHA256、OTA 签名、`sysupgrade -T`、`/tmp` 空间、启动盘和配置备份，
然后调用标准 `/sbin/sysupgrade`。不要手工使用 `-F` 或跳过设备检查。

## 配置与恢复

升级前自动生成配置备份并保留 LAN、PPPoE、IPv4/IPv6、DNS、PassWall、PassWall2、SmartDNS、
AdGuard Home、WireGuard、DDNS 和用户规则。APK/内核模块不会从旧系统包数据库恢复。

初始 root 密码为 `password`，首次登录后必须立即修改；保留配置升级不会覆盖已修改的 root 密码。
