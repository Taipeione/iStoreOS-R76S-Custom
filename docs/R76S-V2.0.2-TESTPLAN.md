# R76S-V2.0.2 测试计划

## 静态/云端门禁

- OpenWrt 25.12.6、RK3576、`friendlyarm_nanopi-r76s`、kernel 6.12.112。
- 512 MiB rootfs、APK enabled、OPKG disabled。
- V1.4.6 direct OTA gate 为 BLOCKED；V2.0.x same-layout OTA 仅为静态门禁 PASS，实机仍为 NOT TESTED。
- sysupgrade Metadata、SHA256、OTA 签名、配置备份和 `/tmp` 空间检查。
- 初始 root hash、LAN-only SSH、无明文密码。
- 选择性迁移排除旧 OPKG/APK 数据库、shadow、init/rc.d 和旧 OTA state。
- AppleEcosystem 85 条、十组应用规则、用户 153 条、WeChatDirect TCP/UDP。

## 模拟测试

在不接触生产块设备的 Linux rootfs/临时目录中测试：

1. V1.4.6 配置备份只恢复允许的网络、DNS、代理和应用数据。
2. `/etc/opkg`、`/etc/apk`、`/etc/shadow`、`r76s_ota_state` 不被选择性恢复。
3. V2.0.x→V2.0.2 的版本比较、设备检查、空间不足和 SHA 错误均 fail closed。
4. PassWall 与 PassWall2 同时启用时 OTA 阻止。
